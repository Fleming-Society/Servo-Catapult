# Servo Catapult

A simple servo-based catapult to teach students how to connect and program an Arduino Uno. Use for 1st Year Arduino introduction or for outreach activities. Adjust material accordingly for audience and time requirements. Session length can be from 45 mins up to 2 hours.

## At a glance

| Item | Details |
| --- | --- |
| Programme | Arduino Controlled Servo Catapult |
| Topics | Arduino, Breadboards, Serial Comms, Analog/Digital |
| Hardware | Arduino Uno, 180° Servo, breadboard, button, wires, 3D printed arm & holder |
| Firmware | Arduino sketch using Servo Library |
| Design tools | Arduino IDE, Fusion 360 |
| Current status | Recovered teaching pack from various sources; technical revalidation is required before another delivery |

NOTE: teaching materials may be incomplete, or old designs. Please verify and prototype before use.
